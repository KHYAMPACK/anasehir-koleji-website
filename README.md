# Anaşehir Koleji — Website (in progress)

**Multi-page website for a private school (K-12 college).**

🚧 In development with the client · Built by [Ekiz Yazılım](https://ekizyazilim.com)

## Overview

- 12 pages: home, schools, education model, academic success, campus life, school radio, FAQ, enrollment/contact, KVKK, privacy
- GSAP-driven animated storytelling on the homepage
- Built-in player for the school's student-run radio station
- Enrollment lead form and WhatsApp lead form

**Stack:** Next.js (App Router) · React · TypeScript · Tailwind CSS · GSAP · Vercel

## Development

```bash
npm install
npm run dev
```
